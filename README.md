# 番茄风格网文创作工作区

一个基于 **Spec-Driven Development** 思路构建的长篇网文创作项目，目标是仿写我吃西红柿《吞噬星空》风格的**科幻+修真+升级流**长篇。

## 项目简介

本项目把"设定"视为单一真相源（Single Source of Truth），由 AI Agent（CodeBuddy / Claude）按设定文件产出正文。所有境界、数值、人物、伏笔都以设定文件为准，避免前后矛盾。

核心理念：
- **风格蒸馏**：提炼番茄写作规则，而不是背诵原文
- **节奏可量化**：每个 arc 都有 beat sheet
- **状态可追踪**：主角状态、战力、伏笔实时更新
- **一致性优先**：所有数值以设定文件为准

## 目录结构

```
├── CLAUDE.md              # 最高写作指令（AI 必读）
├── 00_style/              # 风格指纹（DO/DONT、句式库）
├── 01_worldbuilding/      # 世界观（境界、宇宙、经济、地点）
├── 02_characters/         # 人物卡
├── 03_plot/               # 大纲 + 卷/篇/章节拍
├── 04_continuity/         # 连续性追踪（状态/战力/伏笔）
├── 05_references/         # 参考资料与风格分析
└── 06_output/             # 最终润色稿
```

## 与 AI 协作写作 SOP

### 第一步：冷启动校准
在正式开写前，先让 AI 写**一章样本**，对照 `00_style/` 下三个文件做风格校准。样本可能需要迭代 2-3 次，直到读起来"像番茄"。

### 第二步：按 arc 逐章推进
```
1. 人类：检查当前 beat_sheet.md，确认本章节拍
2. 人类：Prompt："请按 CLAUDE.md 流程写 ch_XXX"
3. AI：按 9 步 SOP 执行，产出正文
4. 人类：审阅 → 若通过，合入 06_output/；若不过，修改 beat 或指令后重写
5. AI：更新所有连续性文件
```

### 第三步：每 5 章做一次连续性体检
```
- 对齐 state_tracker.md 与 protagonist.md
- 清点未回收的 foreshadowing
- 核对 power_ledger.md 与战斗描写
```

### 第四步：每卷结束做风格回归测试
随机抽 3 章丢给 AI 做"风格指纹检测"，看是否偏离 `style_guide.md`。

## 推荐 Prompt 模板

**开写新章节**：
```
请按 CLAUDE.md 的 9 步 SOP 撰写 ch_XXX。
目标节拍：<从 beat_sheet.md 复制>
目标字数：3500
核心爽点：<填入>
务必先读完必读清单，再动笔。
```

**风格校准**：
```
请对照 00_style/style_guide.md 和 do_and_dont.md，
对 ch_XXX 做风格自检，列出不达标的句子和修改建议。
```

## Git 版本管理建议

- **主干**：`main` 只合入通过人类审阅的正文
- **分支策略**：
  - `draft/arc-XX` 用于单个篇章的草稿迭代
  - `spec/*` 用于设定调整
- **提交规范**：
  - `feat(ch-003): 新章初稿`
  - `fix(state): 同步主角念力数值`
  - `spec(power): 新增武尊阶段描述`
- **tag**：每卷结束打 tag `v1-earth-arc01`

## 常见问题

**Q1：AI 擅自改设定怎么办？**
→ 立即回滚，并在 `CLAUDE.md` 的禁令清单第 6 条强调。若多次出现，检查 Prompt 是否未要求先读设定文件。

**Q2：风格飘了怎么救？**
→ 回到 `05_references/style_analysis.md` 复盘；让 AI 读 3 章用户已认可的样本作为风格锚。

**Q3：伏笔太多忘了回收？**
→ 每写 10 章强制扫一次 `foreshadowing.md`，标记"超期未回收"。

**Q4：境界系统要不要原创？**
→ 推荐参考 `power_system.md` 骨架后做局部微调。**一旦定稿，不允许中途大改**，否则需要回溯修改所有已写章节。

**Q5：章节太长/太短怎么办？**
→ 若连续 3 章偏离目标字数 ±500 以上，调整 `beat_sheet.md` 的字数分配，而不是让 AI"凑字数"。

# 苍梧 · 番茄风格修真玄幻创作工作区

一个基于 **Spec-Driven Development** 思路构建的长篇网文创作项目。

- **题材**：东方修真玄幻 + 多元文化交织（对标《莽荒纪》《完美世界》）
- **风格**：我吃西红柿（番茄）笔法 —— 短句、爽点密集、节奏清晰
- **世界**：独立虚构的 **苍梧大陆**，六大文化圈（大梁 / 北漠 / 西陆 / 南疆 / 海外商盟 / 幽冥谷）
- **主角**：肖凯（大梁王朝家道中落世家子）
- **差异化卖点**：不只写"升级爽文"，更写"多元文化交织下的人文魅力"

---

## 一、项目简介

本项目把"设定"视为单一真相源（Single Source of Truth），由 AI Agent（CodeBuddy / Claude）按设定文件产出正文。所有境界、数值、人物、伏笔都以设定文件为准，避免前后矛盾。

### 核心理念

- **风格蒸馏**：提炼番茄写作规则，而不是背诵原文
- **节奏可量化**：每个 arc 都有 beat sheet
- **状态可追踪**：主角状态、战力、伏笔实时更新
- **一致性优先**：所有数值以设定文件为准
- **多元文化为骨**：每种力量都是"道"的不同显化，不做东西方二元对立

### 世界观一句话

> **"路有千万，道归于一。人生而为微光，修行即是追光。"**

## 四、与 AI 协作写作 SOP

### 第一步：冷启动校准（第 1~3 章）

在大规模写作前，先让 AI 写**样本章**（第 1 章），对照风格三件套做校准：
- `00_style/style_guide.md`（8 维度指纹）
- `00_style/do_and_dont.md`（正反例）
- `00_style/signature_phrases.md`（句式库）

样本可能需要迭代 2-3 次，直到读起来"像番茄"。

### 第二步：按 arc 逐章推进

```
1. 人类：检查当前 beat_sheet.md，确认本章节拍
2. 人类：Prompt："请按 CLAUDE.md 流程写 ch_XXX"
3. AI：按 9 步 SOP 执行，产出正文
4. 人类：审阅 → 若通过，合入 06_output/；若不过，修改 beat 或指令后重写
5. AI：更新所有连续性文件（state_tracker / power_ledger / foreshadowing / loose_ends）
```

### 第三步：每 5 章做一次连续性体检

- 对齐 `state_tracker.md` 与 `protagonist.md`
- 清点未回收的 `foreshadowing.md`
- 核对 `power_ledger.md` 与战斗描写的数值一致性
- 扫 `loose_ends.md` 看有无可合并/废止的坑

### 第四步：每卷结束做风格回归测试

随机抽 3 章丢给 AI 做"风格指纹检测"，看是否偏离 `style_guide.md`。

### 第五步：多元文化密度检查（本项目特有）

每 10 章检查一次：
- 是否有外域文化/人物出场
- 外域人物是否有"自己的故事"（不是工具人）
- 有无不经意贴标签（"北漠都野蛮"、"西陆都冷漠"）

## 五、推荐 Prompt 模板

### 开写新章节（第 1 章专用）

```
请按 CLAUDE.md 的 9 步 SOP 撰写第 1 章正文，写入
03_plot/volume_01_qingyu/arc_01_awakening/ch_001.md 末尾的"## 正文"小节下。

动笔前必须先读完 CLAUDE.md 第 3 节列出的全部必读文件（特别是 philosophy.md）。

本章要求：
- 节拍：铺垫 / 字数：3500±300 / 核心爽点：无（纯铺垫）
- 必须埋入 F001 秘信 / F002 青玉扣 / F003 朱砂痣 三条伏笔
- 章末悬念型钩子（秘信内容引发的未解之谜）
- 严禁现代词、穿越词、地球设定词
- 主角须展现"大梁文修"气质（会翻古籍、会引典）

写完后同步更新所有连续性文件，简短汇报本章情况。
```

### 风格校准

```
请对照 00_style/style_guide.md 和 00_style/do_and_dont.md，
对 ch_XXX 做风格自检，列出不达标的句子和修改建议。
统计：平均句长、最长句、爽点数、伏笔数、对白占比。
```

### 多元文化自检（外域章节）

```
本章涉及外域人物 [人名]，请检查：
1. TA 的修炼术语是否符合其文化圈（对齐 races_factions.md）
2. TA 的行为举止是否有文化辨识度（不贴标签）
3. TA 有没有"自己的故事正在发生"
4. 有没有让读者感受到"大梁 ≠ 唯一答案"的哲学暗线
```

## 六、Git 版本管理建议

- **主干**：`main` 只合入通过人类审阅的正文
- **分支策略**：
  - `draft/ch-XXX` 用于单章草稿迭代
  - `spec/*` 用于设定调整
- **提交规范**：
  - `feat(ch-001): 第一章初稿，3500字，埋F001-F003`
  - `fix(state): 同步主角凝气中阶数值`
  - `spec(power): 细化铸魂境跨文化表现`
  - `refactor: 重构世界观为苍梧大陆`
- **tag**：每卷结束打 tag `v1-qingyu-complete`

## 七、常见问题

### Q1：AI 擅自改设定怎么办？
→ 立即回滚，并在 `CLAUDE.md` 的禁令清单强调。若多次出现，检查 Prompt 是否要求"先读必读清单再动笔"。

### Q2：风格飘了怎么救？
→ 回到 `05_references/style_analysis.md` 复盘；让 AI 读 3 章你已认可的样本作为风格锚。

### Q3：伏笔太多忘了回收？
→ 每写 5 章强制扫一次 `foreshadowing.md`，标记"超期未回收"。长线伏笔（⭐⭐⭐⭐以上）每卷必须过一次。

### Q4：境界系统能改吗？
→ **7 境体系一旦定稿不可大改**。一旦中途调整，所有已写章节都要回炉。如需微调（如增加子阶细节），走 `spec/*` 分支。

### Q5：章节太长/太短怎么办？
→ 若连续 3 章偏离目标字数 ±500 以上，调整 `beat_sheet.md` 的字数分配，而不是让 AI 凑字数。

### Q6：外域人物戏份如何把握？
→ 第一卷原则：**外域人物登场不超过 3 章、不抢主角风头**。他们有自己的故事，但镜头 90% 在主角身上。第二卷游历篇会提升外域戏份。

### Q7：反派写得太脸谱化？
→ 检查 `races_factions.md` 末尾的"反派三要素"：动机 / 软肋 / 闪光点。三要素齐全才算合格。

### Q8：主角名字/家人名字想改？
→ 随时可以，但需同步改 `protagonist.md`、`relationships.md`、`state_tracker.md`、已写章节中所有出现处。**越早改成本越低**。

### Q9：跟当前 Claude / CodeBuddy 模型的协作建议？
→ 让它**严格按 CLAUDE.md 的 9 步 SOP 执行**，并在 Prompt 中明确"读完必读清单再动笔"。不要一次让它写多章，单章产出更可控。

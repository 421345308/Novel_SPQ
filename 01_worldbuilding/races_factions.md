# 势力与组织

> 基于 `philosophy.md` 的修行路径和 `continent_geography.md` 的六大文化圈展开。
> **第一卷主战场在大梁青玉郡**，本文件以大梁为主，其他文化圈给出"第一卷需用到"的部分；第二卷起再扩充。

---

## 一、大梁王朝（主角故国 · 第一卷主舞台）

### 1.1 朝廷体系

- **皇室**：当今**明德帝**（踏虚境巅峰），在位 27 年，渐露疲态
- **翰林院**：文修官系统核心
- **兵部**：武修官系统
- **钦天监**：秘法机构（天象、阵法、秘境）
- **锦衣卫**：皇帝直属情报组织

### 1.2 朝廷三大派系

#### ● 周敬安党（全书大反派 · 第一层敌人）

- **首领**：**周敬安**，当朝太师，踏虚境初期
- **主张**："强权新政"——集权、军管、铁腕应对将来的大灾

**做的实打实的恶（必须惩罚）**：
- 构陷肖彦章一族
- 镇压清流派
- 滥用锦衣卫政治屠杀
- 扶植腐败地方官（如赵仲谦）
- 垄断修真资源

**三要素（不脸谱化）**：
- **动机**：20 年前亲见边境屠戮、副将死在他怀里 → 认定"温和派必致亡国"
- **软肋**：那位死去的副将（每年祭日独自悼念）
- **闪光点**：对寒门门生极好；坚持不让儿子周子禾走裙带

**公私明暗**：
- 公：太师、三朝元老、文坛领袖
- 私：寒门出身执念 + 救世狂想
- 明："老臣一片忠心"
- 暗：暗写《苍梧危局论》三万字从未示人

**最终结局**：不死于主角剑下，死于自己制度反噬（爪牙背叛）。临死台词："你以为你赢了？……你才刚开始。"

#### ● 清流派（主角父亲曾属）

- **代表**：**于子和**（御史大夫，凝气巅峰）、**钱景明**（国子监祭酒）
- **主张**：守"文武合一"古制，反对集权
- **现状**：十年前肖彦章被打倒后元气大伤
- **重要复杂性**：清流派**不是纯粹正义**——其中有人间接害过阴氏，主角加入时必须看清

#### ● 皇室宗亲派

- **代表**：**承平王**（皇帝胞弟，铸魂境初期）
- **立场**：表面中立，对周敬安有提防
- **与主角**：第二卷或第三卷的关键助力

### 1.3 民间势力

- **苍梧书院**：青玉郡内的文武双修学府，主角入学之地
  - **院长**：**楚彦君**（铸魂境初期，昔日翰林，与肖彦章是同窗）
  - 内设文科、武科、秘法科

### 1.4 青玉郡（第一卷舞台）

#### 郡府

- **郡守**：**赵仲谦**（凝气巅峰）—— 周党地方代理
  - **三要素**：动机=为儿子赵元景搏未来；软肋=独子；闪光点=年轻时也曾治水有功
  - **结局**：第 25 章倒台，临走冷笑"下一任未必比我好"（B 线明示）
- **独子**：**赵元景**（淬体巅峰）—— 第一卷阶级仇敌
- **郡丞**：**陈守一**（凝气中阶）—— 清流派暗中遗脉

#### 暗影势力

- **百草堂**：表面药铺，实为幽冥分舵
- **阴无常**（铸魂境巅峰）：幽冥派驻青玉郡的高手
  - **三要素**：动机=家族血仇（清流派曾间接害他）；软肋=幼妹的牌位；闪光点=对手下不亏待
  - **第一卷结局**：第 28 章看到肖凯朱砂痣后撤退（伏笔）

## 二、北漠汗国（草原萨满 · 第一卷副线）

### 2.1 政体

- **乌桓汗**：北漠九大部族联盟之主
- **九大部族长老**：议事会
- **大萨满**：每族一位，精神领袖

### 2.2 信仰核心

**长生天**——万物之源，不具人形。配合"先祖英灵"祭祀。
- 春祭、出征祭、成年礼（12 岁血脉觉醒）
- 禁忌：不杀幼狼、不焚草原、不对长生天发死誓

### 2.3 内部矛盾（呼延铁木背景）

- **乌桓汗 vs 呼延部**：呼延部因拒绝"血祭幼狼"被打压
- **呼延铁木**（凝气巅峰）：呼延部流亡武士，独眼，左手戴狼牙铜环
  - 来青玉郡谋生护镖
  - 怀里揣着风干的银狼牙（救幼狼时偷偷留的）
  - 每次喝酒前会把银狼牙放在酒碗边

### 2.4 与大梁恩怨

- 百年前北伐血战，互有伤害
- 当代冷战，边境贸易
- 民间仍流传"北漠战歌"

## 三、西陆联邦（议会+格物 · 第一卷副线）

### 3.1 政体

- **联邦议会**：13 城邦代表组成
- **星枢科学院**：最高学术殿堂
- **铸剑公会**：技术垄断
- **圣光教会**（Ecclesia Lumina）：信众覆盖 70% 人口

### 3.2 圣光教会（关键设定）

- 教义：**"圣光"即"道"，理解即朝圣**
- "格物即圣礼"——科学发现是对圣光的颂扬
- **不反对修真**（与地球中世纪教会的关键区别）
- **光政分立**原则，但与议会有摩擦

### 3.3 阶级

| 阶层 | 状况 |
|------|------|
| 旧贵族 | 失实权，议会约 30% 席位 |
| 新兴资产阶级 | 公会大老板、商会，新兴势力 |
| 学者阶层 | 星枢科学院，超然党派 |
| 工匠 | 公会成员，独立工会 |
| 神职 | 介于贵族与资产阶级 |
| 平民 | 工人、佃户、水手 |
| 游学者/冒险者 | 流动阶层 |

### 3.4 艾琳家族（关键伏笔）

- **薇斯特菲尔德伯爵家族**：旧贵族之一
- **100 年前**：青年贝特朗·薇斯特菲尔德爱上一位东方修士被处死
- 自此家族严禁与东方人深交
- **艾琳**：庶出，星枢学院学员；笔记本上偷抄大梁诗词；详见 `02_characters/allies/elin_westerfeld.md`

### 3.5 经济

- **货币**：晶元（机器可识别的标准化灵石提纯）
- 已出现原始银行业：**西陆联合钱庄**

## 四、南疆十万山（蛊医巫道 · 第一卷副线）

### 4.1 政体

无统一王权，**母系残痕显著**。
- 三大蛊脉由女子掌权（碧鳞 / 赤虺 / 黑雾）
- 男子可从医、武勇，但不掌大事

### 4.2 信仰

- 祖灵崇拜（每家供"祖婆婆"神位）
- 蛊神（碧鳞信"青鳞神母"、赤虺信"烈火祖神"）
- 自然共生

### 4.3 蛊医 ≠ 邪术（文化纠正）

- **蛊医**：用蛊治病，碧鳞一脉严守此道
- **蛊术**：用蛊攻击伤人，多为黑雾所为
- 大梁民间视蛊为邪术 = 对未知的恐惧（**主角第一次见阿娆时也带这种偏见，需在剧情中化解**）

### 4.4 阿娆（关键人物）

- 碧鳞一脉游医，铸魂境初期
- 北上青玉郡为寻"通玄草"救阿婆婆
- 详见 `02_characters/allies/`（待补卡）

## 五、海外商盟（契约修行 · 第一卷副线）

### 5.1 政体

- **十二使议事会**：商人寡头
- **契约法体系**：贯穿一切

### 5.2 契约分级

- **口头契**：小额，违约仅道义压力
- **书面契**：中额，需两证人签押
- **血契**：大额，以灵血为印，违约者被反噬
- **道契**：稀有，需踏虚境以上才能立，违约被天地共弃

### 5.3 哲学底色

**务实至上**：不问善恶，只看契约。

**但有底线**：
1. 不贩卖活人（战俘奴隶有规范）
2. 不卖能毁文化圈的武器
3. 不替任何势力做掉化神境

### 5.4 孙孛洛（关键人物）

- 表面：青玉郡"同福当铺"账房
- 真实：商盟"十二使"之一，踏虚境初期
- 算盘是踏虚境灵器（可推演短期因果）
- 详见 `02_characters/allies/`（待补卡）

## 六、幽冥谷（反派势力 · 散于各地）

- **谷主**：名讳成谜（化神境）
- **核心**：所有文化圈"被结构碾碎的人"的集合体
- **哲学**：虚无主义——"既然世界容不下我们，就让世界一起死"
- **第一卷代表**：阴无常（详见第 1.4 节）

**重要**：幽冥谷不是纯粹邪魔——其中有不少**被冤枉而走入邪道的正义者**。这是反派不脸谱化的核心。

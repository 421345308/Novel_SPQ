# 苍梧大陆 · 地理与文化圈

> 本书的全部故事舞台。一张大陆，六大文化圈，万法归宗。

---

## 一、大陆总览

**苍梧大陆**——一个面积约等于现实欧亚大陆两倍的虚构世界。灵气充沛，文明繁盛。大陆以**中央昆墟山脉**为脊梁，将大陆一分为东西；以**玄霜商道**为横轴，将大陆一分为南北。

```
                [北漠草原]
                  │
  [西陆联邦] ────[大梁王朝]──── (海) ──→ [海外群岛·商盟]
                  │
                [南疆十万山]
                  │
              [幽冥谷·散于各地]
```

## 二、六大文化圈详解

### 1. 大梁王朝（主角所在文明 · 类东方华夏）

- **地理**：大陆东部广袤平原与丘陵，依天河而立
- **政体**：中央集权的封建王朝，当今"明德帝"在位二十七年
- **修炼哲学**：**"文武合一"**——读圣贤书养浩然气，练武术淬肉身
- **主要势力**：
  - 朝廷：翰林院（文修聚集地）、兵部（武修）、钦天监（秘法）
  - 民间：各大武林门派、书院、游方修士
- **科举制度**：独特的"文武双考"，一人可同时考取文官与武职
- **货币**：以**灵石**为基础，铸有"**大梁通宝**"铜钱（流通于凡俗）
- **典型修炼**：气养万物、剑走偏锋、以文载道
- **故事定位**：主角故土，第一卷、第三卷主舞台

### 2. 西陆联邦（类西方 · 议会制）

- **地理**：大陆西部群岛与大陆架，多港口、大城市
- **政体**：议会共和制。由"十三城邦"各派代表组成"西陆议会"
- **修炼哲学**：**"格物致知"**——理解自然法则即接近道
- **主要机构**：
  - **星枢科学院**：最高学术殿堂，培养格物修士
  - **十三城邦议会**：政治中枢
  - **铸剑公会**：制造各类机械器物
- **科技表现**：
  - 机甲、能量护甲、光能武器、飞艇、铁路
  - **但一切都以修士自身修为为驱动**——机甲无法被凡人操纵
- **货币**：**晶元**（封装提纯灵粉的合金币，与灵石 1:1 兑换）
- **文化氛围**：理性、务实、崇尚学问；有贵族阶层但不禁锢庶民
- **故事定位**：第二卷重要地图，盟友来源

### 3. 北漠汗国（类草原 + 萨满 · 部落联盟）

- **地理**：大陆北部广袤草原、大漠、森林
- **政体**：部落联盟。以**"乌桓部"**为盟主，下辖九大部族
- **修炼哲学**：**"万灵契约"**——与自然之灵、古老兽神缔结契约
- **文化氛围**：尚武、豪迈、重承诺；但部族间斗争激烈
- **典型修炼**：血脉觉醒、图腾附体、灵兽共生
- **货币**：**灵石直接流通**，额外以"**兽晶**"（灵兽内丹）作为硬通货
- **与大梁关系**：百年前曾大战，现为"不战不和"的敌对贸易邦
- **故事定位**：第二卷重要地图，盟友呼延铁木的故乡

### 4. 南疆十万山（类苗疆 + 巫道 · 分散部族）

- **地理**：大陆南部热带雨林、瘴气弥漫的群山
- **政体**：无统一政权，以"**碧鳞一脉**"等三大蛊医世家为精神领袖
- **修炼哲学**：**"蛊虫百草"**——以毒养身、以药救人
- **文化氛围**：神秘、敬畏、女尊；崇拜祖先与自然神灵
- **典型修炼**：炼蛊、用药、血祭；其中"碧鳞一脉"擅用青翠系灵虫（正派），另两脉偏中立与邪道
- **货币**：灵石 + 以物易物（稀有蛊虫本身即硬通货）
- **与外界关系**：相对封闭，但游医行走天下
- **故事定位**：第二卷关键地图，阿娆故乡；解救父亲关键线索之地

### 5. 海外群岛 · 商盟（纯中立第三方 · 经济枢纽）

- **地理**：大陆东海千岛之地，由三百余岛屿组成
- **政体**：**"十二使"议事会**——商盟总舵主下的十二位"执契官"共治
- **修炼哲学**：**"等价交换"**——万物皆可契约化，契约即力量
- **核心组织**：**海外商盟**（全大陆最大贸易网络）
- **文化氛围**：功利、精明、重契约；违约将被反噬（契约本身带有灵力刑罚）
- **典型修炼**：储物空间、金融战法、信用契约
- **货币**：首创"**商盟银票**"——可跨文化圈流通的通用支付凭证
- **与各方关系**：中立，与所有势力做生意，唯独不与幽冥邪修往来
- **故事定位**：第一卷卷末因缘接触，第二卷海外篇主舞台

### 6. 幽冥谷（反派势力 · 散于各地）

- **地理**：**无固定领地**，藏身于各大文化圈的阴影中
- **组织结构**：谷主一人 + 十二长老 + 各分舵
- **修炼哲学**：**"夺舍借寿"**——掠夺他人生命、气运、修为来成就自己
- **文化氛围**：虚无主义、但内部有严格等级
- **典型修炼**：血祭、夺舍、阴魂术、因果镇压
- **与各方关系**：被所有文化圈通缉，但从未根除（原因：幽冥谷主 = 踏虚境巅峰 / 法相境初期）
- **复杂性**：
  - 其中不乏**被冤枉走入邪道的正义者**——比如父亲旧友中有被陷害投幽冥的
  - 也有**厌世的正道天才**——他们选择这条路是因为对正道失望
  - 谷主本人有自己的理由——与"彼岸"之谜相关
- **故事定位**：贯穿全书反派，但每次出场都不让读者觉得"脸谱化"

## 三、中央地带：昆墟山脉

- **地理位置**：大陆脊梁，平均海拔 8000 米
- **特殊规则**：
  - 山脉深处灵气浓度是外界十倍
  - 存在上古战场遗迹、失落文明
  - 诸多文化圈都有"朝圣 / 探险"传统
- **政治地位**：中立，由各文化圈默认共享
- **剧情定位**：**第三卷重要场景**——全书关键秘密埋藏处

---

## 四、横贯东西的交通动脉：玄霜商道

- **功能**：从西陆联邦东境穿越北漠边缘、过昆墟山北麓、入大梁西陲
- **守护者**：海外商盟与各地官方共同维护
- **文化意义**：**各文化圈修士相遇的主要场所**
- **剧情定位**：第二卷主角"游历篇"的主要行进路线

## 五、第一卷故事舞台：青玉郡（大梁东陲）

> 第一卷**不出青玉郡**。小地图写扎实，比画十张大地图更有价值。

### 地理位置
- **归属**：大梁王朝东海道 · 青玉郡
- **位置**：大梁东部边陲，紧邻东海
- **地位**：既是大梁边境，又是海外商盟最常登陆的港口之一
- **文化混杂度**：**整个大梁最开放的郡**——各文化圈都有影子

### 青玉郡主要地标

| 地点 | 类型 | 描述 |
|------|------|------|
| **青玉镇** | 主角所在 | 郡南小镇，山野环绕，民风朴实 |
| **青玉郡府城** | 行政中心 | 十万人口大城，郡守衙门所在 |
| **苍梧书院** | 修真学府 | 大梁东海道最高学府，文武双修 |
| **同福当铺** | 商盟据点 | 看似当铺，实为海外商盟分部（孙孛洛所在） |
| **黑风岭** | 冒险之地 | 郡东北，多灵兽出没，主角首次历练地 |
| **幽潭** | 灵气秘境 | 郡西山中，有水灵气漩涡，适合淬体境修炼 |
| **北郊古战场** | 上古遗迹 | 百年前大梁与北漠激战处，阴气浓厚，有机缘有风险 |
| **青玉港** | 对外门户 | 海外商盟商船停靠处，外域人最多 |

### 为什么选青玉郡做第一卷舞台？
1. **大梁文化为底**——主角文化根基自然建立
2. **边陲开放**——外域修士出现毫不突兀
3. **地大物博**——够第一卷 25~30 章充分施展
4. **留有余地**——郡北的昆墟山脉余脉、郡东的海外，都是第二卷自然延伸

## 六、时间流速 & 空间设定

- **本书为单一世界**，无跨宇宙、无时间差
- 灵气浓度由低到高：大梁（中）、北漠（中）、南疆（高）、西陆（低但有能量晶替代）、海外（中）、昆墟山脉（最高）
- **各文化圈间的旅行**：
  - 骑马从大梁东陲到西陆边境：约 4~6 个月
  - 乘商盟飞舟：约 1 个月
  - 踏虚境修士御空：约 10 日
  - 化神境修士：数息之间

# 标志性句式与场景模板库

> 本文件记录的是**句式结构**与**场景写法**，不是直接抄原文。使用时替换变量 `{主语}` `{境界}` `{动作}` 等。
>
> **重要**：本书是"番茄节奏 + 金庸底蕴 + 大明人性 + 西方经典异域感"的融合作品。所有句式都应**保留番茄的爽点工程学骨架**，但在情感锚点、文化细节处加入金庸味与大明味。

---

## 一、人物亮相句式

### 大梁/江湖式（金庸味）

1. `{人物名}{动作进入}，{衣着特征}，{眼神/气质描述}。`
   - 例：肖凯推门进院，粗布青衫，眉目沉静。

2. `{时间/地点}，{人物名}{动作}，{动作细节}。`
   - 例：青玉镇外溪畔，肖凯立在溪石上，手中那柄青锋剑旧得连鞘漆都剥落了一半。

3. `{标志性物件}先于人{动作}。`
   - 例：一柄青锋剑先于人破水而出。
   - 例：那本《资治通鉴》合上的声音，比脚步先到。

### 战场/危机式（番茄爽点骨架）

4. `一道{颜色}身影{动作}而来，{人物名}{动作}。`
   - 例：一道靛蓝身影自巷口走来，阿娆提着药箱，脖间一串青翠灵虫。

5. `「{台词}」` + `{人物名}{动作出现}。`
   - 例：「肖少爷,该上路了。」阴无常自百草堂阴影中走出，眼眸如冷井。

### 北漠式（豪爽）

6. `{人物名}{动作豪迈}，{身上特征}。`
   - 例：呼延铁木哈哈大笑，独眼里的精光比烈酒还烈。

### 西陆式（理性）

7. `{人物名}合上手中{物品}，{动作}，{冷静的下一句}。`
   - 例：艾琳合上手中的笔记本，推了推单片眼镜：「你的内息，第十二个周天断了。」

## 二、情绪反应句式

### 通用（番茄基础款）

1. `{人物名}瞳孔骤缩。`
2. `{人物名}眼中精光一闪。`
3. `{人物名}嘴角微不可察地一勾。`
4. `{人物名}脸色一变，退了半步。`
5. `{人物名}倒吸一口冷气。`
6. `{人物名}的呼吸一滞。`

### 大梁/文修式（金庸味）

7. `{人物名}面色不动，唯指节发白。`
8. `{人物名}垂眸，半晌未语。`
9. `{人物名}的手停在了半空。`
10. `{人物名}笑了一下，笑得很浅。`

### 大明式（藏锋）

11. `{人物名}没说话，只是把茶碗轻轻放下。`
12. `{人物名}笑了一声——这一声，比哭还难听。`
13. `{人物名}的目光在{某物}上停了一息，又移开了。`

**规则**：同一章同一种反应用法不超过 2 次。每章可混用各文化圈风格，但要符合人物身份。

## 三、战斗描写模板

### 模板 A：出招式（带境界与文化标识）

```
「{招式名}！」
{人物名}{动作}，{修行路径相关动作描述}。
{威力描述——可量化的环境破坏}。
{对手反应（带文化辨识度）}。
```

示例（大梁文修式）：
> 「拂晓——」
> 肖凯长剑斜挑，剑势舒缓如朝霞初升。
> 一道剑气自他指尖延出，三丈外的青石"咔"地裂开一寸。
> 赵元景跟班瞳孔骤缩，下意识后退半步。

### 模板 B：碰撞瞬间（番茄经典）

```
「轰——！」
{两种力量描述}正面相撞。
{环境破坏：地面/空气/周围建筑}。
{尘烟散后}，{胜负状态}。
```

示例：
> 「轰——！」
> 青白剑光与漆黑魔爪硬生生相撞。
> 方圆十丈地面崩裂，碎石漫天。
> 烟尘散去，肖凯单膝撑地，左肩血染半身。
> 阴无常退了半步，长袖间一道红痕渐渐渗出。

### 模板 C：战斗转折（番茄爽点）

```
就在{对手}得意/发动绝招时，{主角}{意料之外的动作}。
{对手的震惊}：「你……你怎么{疑问}？！」
{主角淡然回应}。
```

### 模板 D：跨文化战斗（本书特色）

```
{主角的招式}撞上{外域对手的招式}。
{两种修行路径的"翻译"}——
{主角心里}：「原来{对手文化}的{术语}，对应的是{大梁术语}。」
```

示例：
> 肖凯一剑刺出，《清霜剑典》的"霜满弓"。
> 那西陆游侠的能量盾应声而碎——但盾后又涌出第二层光罩。
> 肖凯心中一震：「能量晶石的多层共振——这是西陆的'阵法'。」

## 四、突破描写模板（5 段式）

```
[触发]
{触发事件——大战胜利/吞丹/感悟/血脉激发}。

[阻碍]
体内{灵力描述}开始{动词}。
但有一道{壁垒/屏障}横亘在前。
{主角}{动作：咬牙/调息/运转功法}。

[转机]
就在他{即将放弃/坚持不住}的瞬间——
{转机事件：丹药生效/血脉觉醒/外援/顿悟}。
壁垒裂开一道缝隙。

[跃迁]
{数值阶梯：灵力值 X → Y → Z}。
{光芒/天象/法则反应}。
{境界名}！{人物名}{情绪}。

[体验]
他试着{动作：抬手/感知/出招}。
{新境界的具体表现：威力/感知/速度}。
{内心一句}：「{感慨/确认}」
```

示例（淬体→凝气）：
> 肖凯盘膝坐于黑风岭顶。
> 体内灵力奔涌，撞向丹田壁垒。
> 灵力值：92 → 95 → 99……
> 卡住了。
> 他咬牙调息，《浩然正气诀》的心法在脑海中翻涌。
> 父亲的话忽然浮上心头：「壁垒不在丹田，在心。」
> 他闭眼。
> 灵力值：99 → 105 → 132……
> 「啵"——一声极轻的脆响。
> 凝气初阶！
> 他缓缓睁眼，远处溪畔一只白鹭振翅而起的细微响动，他都听得一清二楚。

## 五、清点战利品模板（保留番茄味，加文化注脚）

```
{主角}{动作收起战利品}。
- {物品 A}：{出处/价值/可能用途}
- {物品 B}：{出处/价值/可能用途}
- {物品 C}：{出处/价值/可能用途}
{主角心里}：「{盘算/感慨}」
```

示例：
> 肖凯翻看着妖兽尸体附近的物事。
> - 二阶妖兽兽晶一枚（约值十枚下品灵石，可炼丹可换钱）
> - 一柄淬过的猎户用铁刀（凡品，但开过血）
> - 半截丹瓶残片（有南疆碧鳞一脉印记——这处怎么会有？）
> 肖凯眼神微凝。
> 黑风岭的事，比他想的复杂。

## 六、旁观者反应模板（烘托主角）

### 通用爽点款（番茄）

```
{旁观者甲}倒吸冷气：「这……这是{境界}？」
{旁观者乙}目瞪口呆：「才{年龄}？！」
{旁观者丙}喃喃：「{赞叹金句}」
```

### 大梁书院式（金庸味）

```
{老者}抚须不语，眼中却有了精光。
{年长弟子}对身旁人低声：「此子……」
{年长弟子}没说完。
他不必说完。
```

示例：
> 苏长老抚须，半晌未语。
> 楚彦君对身旁的钱执事低声道：「此子……」
> 楚彦君没说完。
> 他不必说完。

## 七、钩子型章末模板

### 钩子 A：敌袭

```
{主角}正{日常动作}，忽然——
{异常感知——气息/杀机/空间波动}。
{主角}{紧绷反应}。
{新敌人/威胁降临的首句描述}。
```

### 钩子 B：突破中断

```
就在{主角}即将突破的瞬间——
{意外事件打断}。
{悬念：是谁？为何？}
```

### 钩子 C：身份揭示

```
{角色}缓缓转身。
{主角震惊}：「是你……？！」
```

### 钩子 D：新目标激发

```
{主角}看着手中{物品/信息}，{表情}。
他低声念出{关键信息}。
{主角内心}：「下一步……」
```

### 钩子 E：悬念型（本书特色 · 大明味）

```
{主角}{动作}，{物品归位}。
{某细节让主角心中一动}。
{主角的低声自语}。
{留白的一句}：「事情远比他以为的，{深 / 复杂 / 早}。」
```

示例（第 1 章末）：
> 肖凯把薄绢按原样折好，塞回暗格。
> 月色清冷，烛火摇了一摇。
> 「凡有非常事，勿信外人。」
> 他低声念了一遍。
> 十年前的事，远比他以为的，还要深。

### 钩子 F：结构性回响（本书冲突体系特色）

主角打倒一个反派后，留出"问题没真正解决"的余韵。

```
{反派倒下/落败}。
但{主角}的目光落在{某细节——表明这只是冰山一角}。
{主角内心}：「他不是一个人。」
{留白}。
```

示例（拟卷一末）：
> 阴无常退入夜色。
> 肖凯按着剑柄，目光却落在百草堂账本残页上——
> 那一页，写着青玉郡守府的印鉴。
> 还有，京都礼部一位侍郎的名字。
> 他不是一个人。
> 这远不是结束。

## 八、金句库

### 主角口吻（克制版 · 大梁文修少年）

1. 「够了。」（动手前）
2. 「承让。」（对友）
3. 「父亲教过我。」（引家学）
4. 「我肖家虽已败落，却不欠你一个赔礼。」（对欺辱者）
5. 「若事有可为，我便去做。」（立志）
6. 「不打；但你不该来。」（对宵小）
7. 「我说过的话，做得到。」（承诺）
8. 「读懂别人的字，先读懂他不写的字。」（引父训）
9. 「他不是一个人。」（看见结构）
10. 「这一仗，我替我父亲打。」（替父复仇时）

### 反派金句（不脸谱化）

11. 「你以为你赢了？……你才刚开始。」（周敬安临死）
12. 「我做的恶，是真的恶——但不止我一个人在做。」（结构性反派的自白）
13. 「我也曾是被踩在地上的人。」（阴无常等"灰度"反派）

### 友人金句（多元文化）

14. 「这酒我记下。」（呼延铁木 · 北漠）
15. 「'气'和'理'，可能是同一件东西的两个名字。」（艾琳 · 西陆）
16. 「心净，骨硬。」（阿娆评主角 · 南疆）
17. 「物有本心，人亦如是。」（孙孛洛 · 海外商盟）

**规则**：
- 金句每章最多用 1 条
- 主角金句要克制（金庸味）
- 反派金句要有重量（大明味）
- 友人金句要有文化辨识度

## 九、过渡句模板

### 时间过渡

- `三日后——`
- `半月后，青玉郡府。`
- `夜色渐深。`
- `烛尽，烛复燃。`（克制式）
- `次日清晨，{时间标志事件}。`

### 空间/POV 过渡

- `与此同时，{地点}——`
- `时间回到一个时辰前。`
- `此时，{某地某人正在做什么}。`
- `「此事，到此为止。」`（场景切断）

### 大梁特色

- `三更鼓刚响过。`
- `天将破晓。`
- `烛火已是最后一寸。`

## 十、文化味专项句式（本书特色）

### 大梁士林对话格式

```
「{敬称}所言，{委婉评价}。」
「{反诘}？」
「{引经据典——一句即可}。」
「……」
{某人沉默，或转身}
```

示例：
> 「楚先生所言，恕在下不敢苟同。」
> 「钱执事请讲。」
> 「《孟子》云：'民为贵，社稷次之'。若苛法代仁政，恐失民心。」
> 楚彦君没说话，只把茶碗轻轻放下。

### 北漠豪爽对话格式

```
{粗豪笑声}。
{比喻——用草原物事}。
{直接的承诺或挑战}。
{动作：拍肩/敬酒/亮剑}
```

示例：
> 呼延铁木哈哈大笑，独眼里的精光比烈酒还烈。
> 「兄弟，你这一剑，比北漠的西风还利。」
> 他从腰间扯下一支白狼骨哨，塞进肖凯掌心。
> 「他日有难，吹三声——草原之上，必有人应。」

### 西陆理性对话格式

```
{合上书/调整器物}
{逻辑推论一句}
{反问主角的预设}
{转折/自问}
```

示例：
> 艾琳合上《大梁诗经》。
> 「你们说'气'入丹田。我们说'能量'入丹田。」
> 她推了推单片眼镜：「术语不同，物理是同一个。」
> 「你不觉得，这本身就是一件——美的事吗？」

### 南疆神秘对话格式

```
{话不多，话之间留长}
{用自然/虫物作比}
{留白多于明说}
```

示例：
> 阿娆看了肖彦章一眼。
> 半晌。
> 「你父亲的伤——」
> 又是半晌。
> 「不是杖伤。是钉子，钉在了魂上。」

### 海外商盟务实对话格式

```
{微笑，但不动神色}
{先报价/利害}
{暗藏让步空间}
{以契约为底线}
```

示例：
> 孙孛洛笑呵呵地把砚台翻来覆去地看。
> 「这砚——若是真品，五十枚上品灵石。」
> 他抬眼：「肖少爷，您今日卖的不是砚——是肖家的下半生。要不要再想想？」

## 使用原则

1. **不要堆砌**：一章中各文化圈句式各用 1-2 处即可
2. **要符合人物**：呼延绝不会说大梁士林话，艾琳绝不会用大梁文言
3. **保留番茄骨架**：开篇短句、章末钩子、爽点节奏，永远不丢
4. **塞肉而非炫技**：句式服务于场景，不要为用而用

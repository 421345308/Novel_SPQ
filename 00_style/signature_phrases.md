# 番茄标志性句式与场景模板库

> 本文件记录的是**句式结构**与**场景写法**，不是直接抄原文。使用时替换变量 `{主语}` `{境界}` `{动作}` 等。

---

## 一、人物亮相句式

1. `一道{颜色}身影破空而来，{人物名}{动作}。`
   - 例：一道黑色身影破空而来，林墨踏空而立。

2. `{人物名}出现在{地点}，{动作}，眼中{情绪}。`
   - 例：林墨出现在山巅，背手而立，眼中精光一闪。

3. `"{台词}"` + `{人物名}{动作出现}。`
   - 例：「是谁？」林墨转身，剑已出鞘。

---

## 二、情绪反应句式

1. `{人物名}瞳孔骤缩。`
2. `{人物名}眼中精光一闪。`
3. `{人物名}嘴角微不可察地一勾。`
4. `{人物名}面色一变，退了半步。`
5. `{人物名}脸色铁青，双拳紧握。`
6. `{人物名}倒吸一口冷气。`
7. `{人物名}心中一凛：「{内心话}」`
8. `{人物名}的呼吸一滞。`

**规则**：同一章同一种反应用法不超过 2 次。

## 三、战斗描写模板

### 模板 A：出招式

```
{招式名}！
{人物名}{动作}，{武器/念力描述}{动词}而出。
{威力描述——波及范围/数值}。
{对手反应}。
```

示例：
> 「裂空斩！」
> 林墨双手合剑，一道青白剑气激射而出。
> 剑气所过，空气被撕裂出一道三米长的真空带。
> 黑袍人瞳孔骤缩，身形急退。

### 模板 B：碰撞瞬间

```
"轰——！"
{两种力量描述}正面相撞。
{环境破坏：地面/空气/周围建筑}。
{尘烟散后}，{胜负状态}。
```

示例：
> 「轰——！」
> 青白剑光与漆黑魔爪硬生生相撞。
> 方圆十丈地面崩裂，碎石漫天。
> 烟尘散去，林墨稳稳站立，黑袍人已退出百米。

### 模板 C：战斗转折

```
就在{对手}得意/发动绝招时，{主角}{意料之外的动作}。
{对手的震惊}："你……你怎么{疑问}？！"
{主角淡然回应}。
```

## 四、突破描写模板

```
体内{能量描述}开始{动词}。
{数值变化}：{旧值} → {新值}。
{感官描述——视觉/听觉/触觉至少两项}。
{境界名}！{人物名}{情绪}。
{境界效果——视野/力量/感知拓展}。
```

示例：
> 念力奔涌，冲击丹田壁垒。
> 念力值：298 → 312 → 335……
> 林墨只觉耳中轰鸣，眼前天地骤然变得清晰。
> 武者巅峰！他缓缓睁眼。
> 百米外蚂蚁搬家的轨迹，他都看得一清二楚。

## 五、清点战利品模板

```
{主角}挥手收起{数量}{物品类}。
储物戒内，{清单：
- {物品 A}：{用途/价值}
- {物品 B}：{用途/价值}
- {物品 C}：{用途/价值}
}
{主角心里}：「{满足/盘算}」
```

示例：
> 林墨抬手一收，三具尸体消失不见。
> 储物戒光芒微闪：
> - 玄铁剑一柄（宗师级武器，可换三十万星币）
> - 凝魂丹三枚（冲击武者巅峰必备）
> - 星图残页一张（疑似通往外界的线索）
> 林墨眼神一亮。
> 够了。下一步，可以动身了。

## 六、旁观者反应模板（烘托主角）

```
{旁观者甲}倒吸冷气：「这……这是{境界}？」
{旁观者乙}目瞪口呆：「才{年龄}？！」
{旁观者丙}喃喃：「{赞叹金句}」
```

示例：
> 长老倒吸一口冷气：「这……这已经是武师境界？」
> 外门弟子目瞪口呆：「他……才十八岁啊！」
> 一旁的大长老喃喃：「此子不凡，千年难遇。」

## 七、钩子型章末模板

### 钩子 A：敌袭
```
{主角}正{日常动作}，忽然——
{异常感知——气息/杀机/空间波动}。
{主角}{紧绷反应}。
{新敌人/威胁降临的首句描述}。
```

### 钩子 B：突破中断
```
就在{主角}即将突破的瞬间——
{意外事件打断}。
{悬念：是谁？为何？}
```

### 钩子 C：身份揭示
```
{角色}缓缓转身，{掀开兜帽/露出真容}。
{主角震惊}：「是你……？！」
```

### 钩子 D：新目标激发
```
{主角}看着手中{物品/信息}，{表情}。
"原来如此……原来如此！"
{主角内心}：「下一站，{新地点/新敌}。」
```

## 八、金句库（主角口吻）

1. 「想杀我？你不配。」
2. 「挡我者，死。」
3. 「这就是你的底牌？」
4. 「我说过，我要你十倍奉还。」
5. 「不是我太强，是你太弱。」
6. 「我的世界，没有认输这两个字。」
7. 「你们以为我三年苦修是为了什么？」
8. 「该上路了。」（对敌）
9. 「兄弟，欠你的，这次还。」（对友）
10. 「给我一个机会，我就能碰到那个高度。」

**规则**：金句每章最多用 1 条，过度使用会变油腻。

## 九、过渡句模板

- `三日后——`
- `与此同时，在千里之外的{地点}。`
- `时间回到一个时辰前。`
- `"此事，到此为止。"`（用于场景切断）
- `夜色渐深。`（用于时间跳跃+氛围切换）

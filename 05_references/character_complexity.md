# 复杂人性写作核心条款

> 对标《大明王朝1566》《琅琊榜》。所有重要角色（不只是反派）都按此办。

---

## 一、人物四面法（核心）

每个重要角色，写作前必须想清楚这四面：

| 面 | 含义 | 示例（父亲肖彦章） |
|----|------|------|
| **公** | 身份/职责要求他做什么 | 流放罪臣，谨守本分 |
| **私** | 个人欲望/恐惧/执念 | 想为亡友雪冤、护妻女 |
| **明** | 台面上说出来的 | "病了，写不动" |
| **暗** | 心里真正的算盘 | 仍与京都旧友通密信 |

**铁律**：每个重要角色出场，**至少展示其中两面的张力**。

---

## 二、反派三要素（必须齐全）

写反派前必须填这张表，缺一项就是脸谱化：

| 要素 | 含义 |
|------|------|
| **动机** | 他为什么做这件恶事？(必须可被理解，但不被认同) |
| **软肋** | 他有什么舍不下的？(让他显得是人) |
| **闪光点** | 他在某个具体的小事上，是好的 |

**反派可以被理解，但他做的恶不能被洗白。**

### 已设定的反派三要素速查

- **周敬安**：动机=20年前边境屠戮的创伤+寒门救世执念｜软肋=死去的副将｜闪光点=对寒门门生极好
- **阴无常**：动机=家族血仇（清流派曾间接害他）｜软肋=幼妹的牌位｜闪光点=对手下不亏待
- **赵仲谦**：动机=为儿子赵元景搏一个未来｜软肋=独子｜闪光点=年轻时也是清廉之人，曾治理过一次水灾

---

## 三、正面人物的弱点（不可缺）

| 角色 | 弱点 |
|------|------|
| 肖凯（主角） | 过度替别人扛、自我牺牲倾向、对家人有时显得太硬 |
| 苏砚清 | 嘴硬、不愿承认自己的恐惧、对父亲的死有"如果当年我..."的执念 |
| 艾琳 | 用学术语言逃避情感、家族认同的撕裂感 |
| 呼延铁木 | 嗜酒、对北漠汗有未消的恨意会影响判断 |

**没有弱点的正面人物 = 纸片人。**

---

## 四、写作时的三个动作

1. **用行为代替独白**：心理戏放在动作里（颤抖的手、按住剑鞘的指节）
2. **配角也要厚度**：哪怕只出场 1 次的菜市场老王，给他一个细节（独子去年北征牺牲）
3. **矛盾时刻定义人**：让人物在两难中选择 —— 选择本身就是人物画像

## 五、自检清单（每章写完核对）

- [ ] 本章重要角色的"四面"展示了至少两面？
- [ ] 反派"三要素"齐全？
- [ ] 正面人物有展现弱点？
- [ ] 是否有"利益关系网"暗示？
- [ ] 是否用行为代替了独白？
- [ ] 是否有"矛盾时刻让人物自己定义自己"？
- [ ] 配角是否至少有一个细节让他活起来？

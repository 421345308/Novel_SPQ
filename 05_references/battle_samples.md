# 番茄战斗描写规律

> 番茄战斗段落是全文最容易"形似神似"的部分。本文总结其底层规律。

---

## 一、战斗四要素（铁律）

每场战斗必须包含：

1. **招式名**：必须有名字，不能"一掌拍下"
2. **能量等级**：念力数值 / 法则等级 / 武器品级，要量化
3. **环境破坏**：地面裂、山崩、空气波动，让读者"看见"威力
4. **对手反应**：表情、动作、退步、内心独白（不超过 1 句）

四要素缺一即视为不合格战斗。

---

## 二、战斗节奏曲线

### 单场战斗的"五拍曲线"

```
拍 1：对峙（短，1-2 段，气氛压制）
   ↓
拍 2：试探（中，2-3 段，互探虚实）
   ↓
拍 3：交锋（长，5-8 段，真正打起来）
   ↓
拍 4：转折（短，1-2 段，反转或绝招）
   ↓
拍 5：终结（短，1-2 段，胜负+清点+反应）
```

整场战斗 1500~2500 字最佳。超过 3000 字就拖了。

---

## 三、句式密度

战斗段落的句子要比铺垫段落短 30%。

| 段落类型 | 平均句长 | 段长 |
|---------|---------|------|
| 铺垫段 | 22 字 | 3~4 句 |
| **战斗段** | **15 字** | **1~2 句** |
| 突破段 | 18 字 | 2~3 句 |

### 战斗段示例（节奏标杆）

> 林墨持剑出鞘。
> 一道青光横扫。
>
> 「找死！」黑袍人怒吼。
> 漆黑魔爪拍下。
>
> 「轰——！」
> 剑光与魔爪相撞。
> 方圆十丈地面崩裂。
>
> 黑袍人退了三步。
> 林墨纹丝不动。

---

## 四、对手反应模板（按等级）

### Level 1：小喽啰
- "你……怎么可能！"
- 怒吼一声后被秒
- 无威胁

### Level 2：中阶敌人
- 瞳孔骤缩
- 退两三步
- 嘴角溢血
- 尝试再战或逃

### Level 3：高阶敌人
- 倒吸冷气
- 重新审视主角
- 释放底牌
- 心中震撼："此子……"

### Level 4：BOSS 级
- 长篇内心戏（不超过 100 字）
- 杀招迭出
- 临死惊诧："不可能……我竟然死在……"
- 留下伏笔（暗语、遗物、临终警告）

---

## 五、战斗中的"信息密度"控制

不要写"流水账打架"。每场战斗必须传递新信息：

- 主角学会了一招新的？
- 主角发现自己有新天赋？
- 反派露出了组织的线索？
- 战利品里藏着伏笔？

**没有信息增量的战斗 = 注水**。

---

## 六、典型战斗场景模板

### 模板 A：以弱胜强（主角逆袭）

```
1. 对方报境界，旁观者倒吸冷气（"武师巅峰，他完了！"）
2. 主角不慌，缓缓出招
3. 第一击对方掉以轻心，被压制
4. 对方惊怒，放出真实底牌
5. 主角再次升级（领悟新招/激发血脉/启用奇物）
6. 一击定胜负
7. 旁观者震撼："这……这是武者？？"
```

### 模板 B：势均力敌（成长性战斗）

```
1. 双方互探，三招内分不出胜负
2. 中段进入消耗，互有损伤
3. 关键转折：主角想起家人/战友（情感支点）
4. 爆发新招或顿悟法则
5. 险胜，自身也消耗大半
6. 战后清点 + 思考下一步
```

### 模板 C：碾压式战斗（爽点章）

```
1. 主角境界明显高于对方（用旁观者口吻 cue 出来）
2. 一招制敌
3. 反派临死前发挥几句"恐怖如斯"的赞叹
4. 主角清点战利品
5. 转身离开
```

---

## 七、战斗中的禁忌

❌ 不准用：
- "他使出全身力气"（应该用具体数值）
- "战斗持续了不知多久"（必须给时间）
- "尘埃落定，胜负已分"（陈词滥调）
- "主角浑身浴血，几乎站不住"（番茄主角不要太狼狈）
- 大段"师徒对话式"边打边讲解（拖节奏）

✅ 推荐用：
- "三息之内，他出了七剑。"（具体）
- "战至第三十回合，主角眼神一变。"（节奏感）
- "尘烟散去，黑袍人不见了——胳膊上多了一道剑伤。"（画面感）

---

## 八、战斗描写自检表

写完战斗，逐条打钩：

- [ ] 招式有名字
- [ ] 数值有出处（与 power_ledger.md 一致）
- [ ] 环境破坏有描写
- [ ] 对手反应到位（按等级匹配模板）
- [ ] 句子平均 ≤ 18 字
- [ ] 战斗中有新信息（招式/天赋/线索）
- [ ] 战后有清点或反应
- [ ] 旁观者烘托至少 1 处

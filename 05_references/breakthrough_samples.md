# 境界突破描写规律

> 突破是网文最爽的瞬间。番茄的突破描写有清晰的"五段式"模板。

---

## 一、突破五段式

每次突破必须经历：

```
[1] 触发（外因/内因）
   ↓
[2] 阻碍（瓶颈感、痛苦、压力）
   ↓
[3] 转机（顿悟/资源/外力）
   ↓
[4] 跃迁（数值变化、感官升维）
   ↓
[5] 体验（新境界的初次感受）
```

每段都不能省。

---

## 二、各境界突破特征

### 武者→武师（小突破）

- **触发**：苦修达标 + 一次激烈战斗顿悟
- **资源**：凝魂丹辅助
- **持续时间**：1~2 小时
- **数值跃迁**：念力 100 → 1000（10 倍）
- **新感觉**：念力可外放、视觉/听觉敏锐 3 倍

### 武师→大武师

- **触发**：领悟"念力凝实"
- **资源**：上品丹药 + 兽晶
- **持续时间**：3~5 小时
- **数值跃迁**：念力 1000 → 10000
- **新感觉**：可念力远程攻击、初步飞行能力

### 大武师→武尊（大突破）

- **触发**：领悟一条"域"的雏形
- **资源**：奇遇 + 顿悟（这一阶突破最难）
- **持续时间**：1~3 天
- **数值跃迁**：念力 10000 → 100000
- **新感觉**：体外形成专属"域"，跨星球穿梭

### 武尊→武王

- **触发**：领悟法则雏形
- **资源**：星辰矿 + 跨星系奇遇
- **数值跃迁**：念力 10 万 → 100 万
- **新感觉**：天地法则若隐若现、引动天象

### 武王→武皇（中期最爽突破）

- **触发**：一条法则完整掌握 + 本命武器诞生
- **资源**：本源碎片 + 武皇丹
- **持续时间**：7~10 天
- **数值跃迁**：念力 100 万 → 1000 万
- **新感觉**：本命武器与心相连、星系级感知

### 武皇→武帝

- **触发**：融合两条法则
- **资源**：跨宇宙级机缘
- **数值跃迁**：念力 1000 万 → 1 亿
- **新感觉**："神通"诞生

### 武帝→宇宙尊者（跨阶突破）

- **触发**：本源觉醒 / 跨宇宙体验
- **资源**：宇宙本源
- **持续时间**：30 天 ~ 1 年
- **跃迁**：肉身 / 法则 / 灵魂三重升华
- **新感觉**：与宇宙本源共鸣

### 宇宙尊者→宇宙最强者

- **触发**：完整宇宙法则掌握
- **资源**：起源碎片
- **跃迁**：法则化身
- **新感觉**：可创造、可毁灭

### 宇宙最强者→真神

- **触发**：起源大陆认可
- **资源**：起源大陆本源
- **跃迁**：与宇宙同寿
- **新感觉**：超越文字描述

## 三、突破描写文学技法

### 1. 数字阶梯

突破段落必须有"数字阶梯"——让读者直观感受到跃迁：

```
念力值：298 → 312 → 335 → 380 → 420 → 500……
```

视觉化的数字爬升 + 当主角达到下一阶门槛时，数字突然加速："500 → 1000 → 5000……"

### 2. 感官升维

突破后的"新世界感"必须用 2~3 个感官细节呈现：

- 视觉："百米外蚂蚁搬家的轨迹清晰可见"
- 听觉："屋顶瓦片下蚊虫振翅的频率都能分辨"
- 触觉："空气中念力波动如水流过指尖"

### 3. 天象呼应（中后期突破）

武王及以上突破，加上天象描写：

- 武王：风起云涌
- 武皇：星辰震动
- 武帝：星河倒卷
- 尊者：宇宙共鸣

### 4. 旁观者反应

如果突破时有旁观者，必须给他们一个"目瞪口呆"的镜头。

## 四、突破描写模板

### 模板：标准突破

```
[触发]
{触发事件——大战胜利/吞丹/感悟/血脉激发}。
{主角}{动作}盘膝而坐。

[阻碍]
体内念力开始{动词：暴动/奔涌/嘶吼}。
但有一道{壁垒/屏障}横亘在前。
{主角}眉头紧锁，{动作：咬牙/调息/运转功法}。

[转机]
就在他{即将放弃/坚持不住}的瞬间——
{转机事件：丹药生效/血脉觉醒/外援/顿悟}。
壁垒裂开一道缝隙。

[跃迁]
{数字阶梯：念力值 X → Y → Z}。
{光芒/天象/法则反应}。
{境界名}！{主角}缓缓睁眼。

[体验]
他试着{动作：抬手/感知/出招}。
{新境界的具体表现：威力/感知/速度}。
{内心一句}：「{感慨/确认}」
```

## 五、突破描写禁忌

❌ 不准：
- 一句话突破完事（"罗峰浑身一震，突破了。"）
- 长篇散文化抒情（"天地灵气汇聚，万物共鸣……"）
- 没有代价的突破（"睡了一觉就突破了"）
- 数字模糊（"念力变得很多"）
- 跳过五段式中的任何一段

✅ 推荐：
- 用数字+感官+对比让读者"亲身经历"突破
- 突破后立刻给一个小测试场景（劈树、感知、对战）
- 给突破"留一点遗憾"——未完全消化、还需巩固，为后续戏铺垫

---

## 六、突破频率控制

- 武者→武师：约 15~20 章
- 武师→大武师：约 30~40 章
- 大武师→武尊：约 50~70 章
- 武尊→武王：约 80~100 章
- 武王→武皇：约 100~150 章
- 武皇及以上：每次跨度更大

**关键原则**：境界越高，突破越难，描写越重。武皇以上每次突破单独一章。

---

## 七、突破章自检表

- [ ] 五段式齐全
- [ ] 数字阶梯具体
- [ ] 感官升维 ≥ 2 项
- [ ] 旁观者反应（如有旁观者）
- [ ] 突破后小测试
- [ ] 与 power_system.md 数值一致
- [ ] 没有"散文化"段落
